Detailed Description

DrawingSummaryCompressionSchema Represents compression metadata used to compress and uncompress a drawing or set of drawings based on the maximum values it would need to transmit to represent any given field.

For example, the mat_id field will be represented by the minimum number of bits required to represent the largest mat_id in the database. Any more significant bits are guaranteed to be 0s, and so if we essentially communicate that all bits past a point of significance are 0s, we can omit those places in the compressed data.
