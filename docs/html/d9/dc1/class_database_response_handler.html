Detailed Description

DatabaseResponseHandler This object is bound to the Client object for the application.

Any message received from the server (after the initial key exchanges and connection messages) will be forwarded to the bound ClientResponseHandler and sent to the onMessageReceived function. The DatabaseResponseHandler is owned by the MainMenu object and handles all responses from the server.

void DatabaseResponseHandler::onMessageReceived ( void *&& message,
unsigned int messageSize )
override

Callback function invoked every time the client receives a message from the server which should be forwarded to the application.

Any invalid message is caught by the client object itself and never forwarded to this function, so by this stage, we know that the message is valid (though it could potentially still be corrupted.)

Parameters
messageA bytestream of the raw (decrypted) message data. The client handles the decryption. It is a rvalue reference to indicate the transfer of ownership.
messageSizeThe size of the message bytestream.
