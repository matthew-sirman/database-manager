Detailed Description

DatabaseManager A class for managing connections to the MySQL database underlying the application.

Also contains methods for some specific actions such as reading values for a summary compression schema, and reading/writing drawings to the database.

enum class DatabaseManager::DrawingExistsResponse

DrawingExistsResponse A simple enum for a response from a check if a drawing exists.

Either returns EXISTS if the drawing is found, NOT_EXISTS if the drawing is not found or R_ERROR if there was an error in the process.

Enumerator
EXISTS 

Indicates the drawing exists.

NOT_EXISTS 

Indicates the drawing does not exist.

R_ERROR 

An error occoured while checking the existence of a drawing.
