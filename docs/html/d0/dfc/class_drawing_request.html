Detailed Description

DrawingRequest Inherits from DatabaseQuery.

This type of query requests all the information about a single drawing in the database, as opposed to basic information about many drawings. It functions by being constructed with a matID, the object is then serialised and sent to the server, where the server will populate the drawingData with what it found, and then return the object. The data can then be read from the drawingData attribute.
