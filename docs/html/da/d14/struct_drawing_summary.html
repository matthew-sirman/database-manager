Detailed Description

DrawingSummary Summary data representing an incomplete set of information about a drawing.

The idea is to have a small amount of information summarising the drawing transferred in a search query in order to minimise the network transfer required. The user can then choose to open a drawing in full, which is essentially requesting the remaining information from the server.
