Detailed Description

template<typename T, DrawingComponentConcept ... Ds>
class AreaGraphicsItem< T, Ds >

AreaGraphicsItem inherits QGraphicsItem
AreaGraphicsItem displays and populates the Inspector for any item that would be displayed as an area on the drawing.

Addons must implement both a static brush attribute and static populateInspector function in AreaGraphicsItem.cpp. If either of these don't exist, a linker error will occour, naming what is missing from which AreaGraphicsIte<T, Ds...>.

Template Parameters
TThe addon that is to be displayed.
...DsAny drawing components the addon relies upon, such as an aperture or material.
