enum AddDrawingPageWidget::AddDrawingMode

An enum holding the different modes this object can function in.

Enumerator
ADD_NEW_DRAWING 

A new drawing is being added.

only loads a the next drawing number and create a blank drawing to build upon.

EDIT_DRAWING 

A drawing is being edited.

Loads the drawing being edited and makes changed to the object, which is then reinserted to the db.

CLONE_DRAWING 

A drawing is being cloned.

Copies a provided drawing, provides a new drawing number and ,when finished, is inserted to the db.
