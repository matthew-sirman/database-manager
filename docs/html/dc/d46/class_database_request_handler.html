Detailed Description

DatabaseRequestHandler Inherits from ServerRequestHandler.

This class is responsible for managing requests from the client to access database resources. It acts as a "middle man" and as such can filter out any invalid or unauthorised requests etc.

void DatabaseRequestHandler::onMessageReceived ( Server & caller,
const ClientHandle & clientHandle,
void *&& message,
unsigned int messageSize )
override

Message Received callback function.

When the server receives a message from a client, it is passed to the ServerRequestHandler object set in the server. If this is that object then this function will be called.

Parameters
callerA reference to the server object which called this function.
clientHandleA handle to the client who sent the message so it is possible to formulate a response for the server to return to them.
messageThe message data itself, as a rvalue reference to indicate transfer of ownership..
messageSizeThe length (in bytes) of the message data received.
