Detailed Description

template<typename IType>
class SourceFilter< IType >

SourceFilter Base type for an installable filter object on a DataSource.

The filter should be extended to suit a particular data source. This will filter a data source based on an arbitrary set of criteria.

Interface filter function.

This will return a boolean pertaining to whether or not the element should be left in the result or not. A true value indicates that the element is a member of the filtered set, and a false indicates that it is not.
