Detailed Description

template<typename T, typename... Us>
class AddComponentWindow< T, Us >

A class for creating a window that allows a user to add a new component to the database.

T refers to the component to be created, and the Us parameter pack is all of the types that make up the component, in the order they appear in the relevant ComponentInsert data.

Template Parameters
TThe type of the component to generate the window around.
UsThe composite types that create the main type T.
